Leonida Trophy Atlas — an offline guide and tracker for all 55 GTA VI PlayStation 5 trophies: every guide step cites its sources (160 cited steps, 154 backed by 2+ sources, 11 named sources), a 6-stage roadmap to the platinum, missable flags, 20 PSN count trackers, a spoiler-safe checklist with saved progress, export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off.
