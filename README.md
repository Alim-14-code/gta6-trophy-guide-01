# Leonida Trophy Ledger — GTA VI Trophy Guide & Tracker (PS5)

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. No hero banner: the first screen is the working tool — a compact header (earned count, PSN points, grade split), an audit strip, and a dense three-pane ledger: trophy tracker list, mini-dossier detail pane, and a rail with the Next Up roadmap and per-trophy sources.

Every trophy shows its official name, description and grade as PlayStation publishes them, a guide written in the ledger's own words, and a citation beside every step. Audit strip: 165 cited steps, 55/55 guides with two or more sources, 11 sites. Missable flags: 1 possibly missable (Positive Mental Attitude — the Chapter 1 balcony meditation spot), 5 at risk, 6 unconfirmed, 12 disputed with a Sources Differ panel and an Our Call verdict. Twenty trophies carry an official PSN count, each with a Your Count tracker. Progress saves in localStorage, exports to a file and imports back; filters for story / missable / collectibles / activities / online, search, and a spoiler shield that hides story trophies until earned.

Static files under `app/` — no build step, no network request at runtime. Serve `app/` with any static server and open `index.html`. Hand in with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
